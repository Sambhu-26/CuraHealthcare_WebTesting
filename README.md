CuraHealthCare(https://katalon-demo-cura.herokuapp.com/) is a online medical platform, used for making appointments. 
It has Options : a. Select facility type(dropdown) 
                 b. Apply for hospital readmission(checkbox) 
                 c.RADIO BUTTON 
                 d. Datre picker 
                 e.Comments(input box) 
It has features for toggle, to view history for recently make appointments. 
----> I have created a Selenium framework for this platforms.
